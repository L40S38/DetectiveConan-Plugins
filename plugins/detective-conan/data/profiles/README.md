# 人物の掘り下げ：作品がその人物をどこまで描いているか

> **ネタバレ注意**：このディレクトリの表は、素性（本名・年齢など）や過去の答えを含む。

情報時点は `conventions.md` の「1. 情報時点」に従う。

## ほかのデータとの分担

| データ | 受け持つこと |

| `relationships/` | 誰とどうつながっているか |

- 素性がまだ明かされていないことが伏線・考察になっているときは、脚注に F-・Q- の ID を書く。

## 凡例

### 記号

知識表と同じ記号を使う。セルの記号は「どこまで描かれているか」の程度だけを表し、中身（恋愛の相手、趣味の内容、どの回のどんな回想か、など）と根拠の話数は脚注に書く。

| 記号 | 私生活・過去の列（P1-1〜P1-6、P2-2） | 素性・内面の列（P2-1、P2-3〜P2-6） |
|---|---|---|
| `◎` | その面が話の中心になる回がある | 明かされている |
| `〇` | 具体的な設定として描かれる（名前・中身が出る、何度か触れられる） | 一部だけ明かされている（名字だけ、年代だけ、シルエットだけなど） |
| `△` | 台詞や 1 コマで触れられる程度 | ほのめかされているだけ（作中の推測・匂わせ） |
| `✕` | 描かれていない | 明かされていない |
| `ー` | 該当しない（子どもの「就職後」など） | 該当しない |
| `?` | 確かめていない。**ベースライン（2026-10-18）では、該当しないことが明らかなセル（`ー`）のほかは、すべて `?` にしている** | 同左 |

- 根拠が正史外（劇場版・アニオリ・スピンオフ）の描写だけのときは `†` を付ける（例：`〇†`）。原作と正史外の両方に描写があるときは、セルには原作の記号を書き、正史外のほうが深ければ脚注に書く。
- `?` と `ー` 以外のセルには脚注を付ける。脚注 ID は `[^P<表番号>-<人物ID の C- を除いた部分>]`（例：`[^P1-furuya-rei]`）。1 人につき 1 表で 1 つの脚注にまとめ、列ごとの中身と根拠はその中に書く。

### 過去の区分（表1 の P1-4〜P1-6）

| 列 | 期間 | 含めるもの |
|---|---|---|
| P1-4 幼少期〜中学 | 生まれてから中学校を出るまで | 幼稚園・小学校・中学校のころ |
| P1-5 就職前 | 中学校を出てから、最初に就職するまで | 高校・大学・大学院・専門学校・留学・警察学校 |
| P1-6 就職後 | 最初に就職してから、物語の今まで | 前の仕事・転職・潜入の前後 |

- 数えるのは、回想や過去編で描かれた、物語の今より前の場面だけ。今の高校生活・小学校生活の描写は入れない。
- 列は学校の段階で決める。学校に通っていない時期（飛び級・海外暮らしなど）は年齢で決める。
- 「就職前」と「就職後」の境目は、学校を出て、仕事が生活の中心になった時点にする。学校に通う年ごろのうちは、組織の下にいても、仕事をしていても（子役・プロ棋士・組織の研究など）、P1-4 か P1-5 に入れる。
  - 例：宮野志保は、組織の下で育った子どものころが P1-4、中学を出る年ごろから勉強を終えるまでが P1-5、シェリーとして研究者の仕事が生活の中心になってからが P1-6。
  - 勉強と仕事が重なっている時期は、どちらが中心かで決める。決められなければ `?` にして、脚注に「要確認」と書く。
- 警察学校のような養成機関は、採用後の期間でも P1-5 に入れる。
- まだ就職していない人物は P1-6 を `ー` にする。小学生は P1-5 も `ー` にする。

## 行の選び方

`knowledge-matrix/README.md` の「行の選び方」と同じにする（グループ分けは `characters.md` の人物カードのグループ、個別の行は `characters.md` の順、各グループの先頭に見出し行、最後にまとめ行）。違うのは次の点。

- 「コナンの把握」の列は無い。
- まとめ行に入れるのは、すべての列が `✕`（`†` なし）の人物。書式は `` | ほかの「<グループ名>」：<名前> `<人物 ID>`、… | ✕ | ✕ | … |  | ``。
- `?`（確かめていない）や `ー` が 1 つでもある人物は、個別の行にする。ベースラインでは全員が個別の行になっている。
- 漏れ・重複・並び順・グループの食い違いは `lint_data.py` が見つける（`profiles/0*.md` の表。`timeline.md` は対象外）。
