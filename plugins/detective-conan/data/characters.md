# 人物索引

> **ネタバレ注意**：このファイルは正体・所属・生死などの答えを含む。
> 情報時点は `conventions.md` の「1. 情報時点」を参照。

- 初登場は `scripts/conan_db.py char <名前>` で引いた原作の値。**事件の先頭 File** で、回想や途中の話で初めて出た場合も事件の先頭が出る。database に無い人物は Web で確かめた値か「要確認」。
- 原作より先にアニメ・劇場版・まじっく快斗・スピンオフで登場していた場合は、原作の初登場の後ろに「／先行：」として書く。原作に登場しない人物は「原作には登場しない」と書き、初出の媒体を続ける。
- どの人物がどの劇場版に登場したかは、末尾の「(c) 劇場版への登場」にまとめる。カードには書かない。
- 生死・所属の根拠は、確かめられた範囲で File を書く。確かめられなかったものは「要確認」。
