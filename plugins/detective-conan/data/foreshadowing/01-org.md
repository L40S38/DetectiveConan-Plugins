### F-ORG-003 ボスのメールアドレスを押したときの音は何を表しているのか
- 状態: 回収済
- 重要度: ★★
- 区分: [原作]
- 初出: 原作 File 434（42巻）「ラットゥンアップル」黒の組織と真っ向勝負満月の夜の二元ミステリー — ベルモットがボスにメールを打つ押下音をコナンが録音する。アドレスの数字はまだ出ない
- 経過: File 475（46巻）「封印」奇抜な屋敷の大冒険までの間、コナンが押下音の解読を進める
- 回収: 原作 File 474（46巻）「幻想曲［ファンタジア］」ストラディバリウスの不協和音 で、その事件の犯人・羽賀響輔（絶対音感を持つ）に「シラソラで始まる哀しい曲」を尋ね、羽賀が口笛で童謡「七つの子」を吹いて教える → 原作 File 475 でコナンが「押すと七つの子の最初のフレーズになる」と気づき、アドレス「#969#6261」を解読する
- 内容: ボスのメールアドレスの押下音に意味があるのか
- 関連: 人物 [烏丸蓮耶](../characters.md#C-karasuma-renya)、[ベルモット](../characters.md#C-vermouth)／考察 Q-002
- 備考: 「七つの子」はカラスの歌で、烏丸（からすま）とつながる。羽賀響輔は「ストラディバリウスの不協和音」事件の犯人（メインキャラクターではなくゲスト）
