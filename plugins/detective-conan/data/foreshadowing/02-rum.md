### F-RUM-004 ダイイングメッセージ「ASACA」と将棋の駒は何を意味するのか

- 経過: 原作 File 950「切り取られた文字」（90巻「17年前と同じ現場」）— コナンと沖矢が残りの文字「U MASCARA」を並べ替えて「ASACA RUM」と読む／File 954–957（90巻「裏切りのステージ」）— 波土禄道の曲「ASACA」が出るが「朝カフェ」由来の曲名で無関係（ミスリード）／原作 File 989「ブザービーター」（93巻「燃えるテントの怪」）— 若狭のポケットに駒の形のふくらみが描かれる／File 1008「ホラ♡」（95巻「マリアちゃんをさがせ！」）— 優作と赤井が「U MASCARA」の8文字を「CARASUMA」＝烏丸蓮耶と推理し直す／File 1033「幸運の御守り」（97巻「山菜狩りとクローバー」）— 若狭の回想に、羽田が角行を掲げて「遠見の角に好手あり」と言う場面／File 1051–1052（99巻「牧場に墜ちた火種」）— 安室が現場から消えていた角行の駒（羽田浩司の御守り）を拾う

- 内容: 羽田浩司が残したメッセージが何を伝えようとしていたのか
- 関連: 人物 [羽田浩司](../characters.md#C-haneda-koji)、[若狭留美](../characters.md#C-wakasa-rumi)／考察 Q-009／知識表 [K4-7](../knowledge-matrix/04-haneda-case.md)
- 備考: 「17年前の真相」の副題の一つは「遠見の角行」。「ASACA」の読みは最終的にミスリードで、正しくは「CARASUMA」だった

### F-RUM-006 羽田浩司とアマンダ・ヒューズはどうやって殺されたのか（毒が検出されなかったのはなぜか）

- 状態: 部分回収
- 重要度: ★★
- 区分: [原作]
- 初出: 原作 File 948「握られたハサミ」（89巻「17年前と同じ現場」）— 羽田浩司の死因の不自然さが語られる
- 経過: 原作 File 947「座右の銘」（89巻「婚姻届のパスワード」）— 灰原が、APTX4869 を飲まされた人物のリストでコナンの名前の 2 つ下に羽田の名前を見た覚えがあるとコナンに話す（リストに羽田の名前が描かれたのは File 179「偽りの少女」（18巻「黒の組織から来た女大学教授殺人事件［2］」）の回想が最初）／原作 File 948「握られたハサミ」（89巻「17年前と同じ現場」）— 17 年前にもう薬があったことについて、灰原が「多分、その薬は私の父と母が作った薬。」と話す／原作 File 1005「濃紅の予兆」（95巻「紅の修学旅行」）— 若狭が同じリストをパソコンで見て、「羽田浩司 死亡」に目を留める／原作 File 1153「写り込んだ真実」（108巻「写真に隠された秘密」）— ラムが、メアリーに飲ませた毒薬について、アマンダと羽田を思い浮かべながら、心の中で「同じ毒薬で ある者の時は永遠に止まり…ある者の時は遡る…」と考える（要確認：台詞の文言）
- 回収: 原作 File 1107「遠見の角行」（104巻「17年前の真相［遠見の角行／女王の謀（クイーンズ・ギャンビット）］」）— アマンダはラムから浅香をおびき出すための毒（「組織が開発したこの毒薬」）を使うと脅され、浅香を守るため自ら飲んで死亡。羽田浩司は浅香の居場所を言わなかったため、ラムに同じ毒を飲まされて死亡し、苦しみの中で「CARASUMA」を刻んだ（File 1108「名人の囲い」（104巻「17年前の真相［遠見の角行／女王の謀（クイーンズ・ギャンビット）］」））
- 内容: 二人の死因と、使われた毒の正体
- 備考: 回想の台詞は「組織が開発した毒薬」までで、APTX4869 と名指しした描写は確認できていない。羽田の名前は APTX4869 の被害者リストに載っており（File 179「偽りの少女」（18巻「黒の組織から来た女大学教授殺人事件［2］」）の回想が最初で、File 947「座右の銘」（89巻「婚姻届のパスワード」）で灰原が気づく）、File 1109「女王の謀」（104巻「17年前の真相［遠見の角行／女王の謀（クイーンズ・ギャンビット）］」）でラムが心の中で「やはりこの右目の…時を戻すしかなさそうですねぇ…」「あの薬の効力が…私の想像通りならの話ですがねぇ…」と考える場面もあるため、APTX4869 説は有力だが確定ではない（この場面の台詞は「あの薬」と言うだけで、APTX4869 とも、羽田たちに使った毒と同じ薬とも言っていない）。ただし File 1153「写り込んだ真実」（108巻「写真に隠された秘密」）では、ラムがメアリーに飲ませた毒薬を、羽田たちに使った毒と「同じ毒薬」と考えていて、その毒をベルモットは「自分の妹が作った毒薬」と言っている（File 1049「とても信じられない…」（99巻「天罰くだる誕生パーティー」））。このため、APTX4869（または宮野夫妻が作った前の版）が使われたことはほぼ確実に読めるが、名前で確定する描写はまだない。「右目」は誤記ではなく原作どおり（サンデー掲載時・単行本・アニメ第 1167 話のどれも「右目」）。File 1107「遠見の角行」（104巻「17年前の真相［遠見の角行／女王の謀（クイーンズ・ギャンビット）］」）で 17 年前のラムは「私のこの左眼はねぇ、一度瞳に焼きつけた物は忘れはしないから」「若い頃は両眼ともそうだったんですけどねぇ…」と言っており、この時点で能力が残っていたのは左眼だけだった。その左眼は後に失っている（File 1100「煙滅」（103巻「怪盗キッドと王冠マジック」）で脇田が心の中で「左目があった頃なら…別ですけどねぇ…」と思い、File 1150「混沌の追跡者たち」（108巻「混沌の行先」）のラムの回想に赤井務武の「その厄介な左眼を頂こうか」という台詞が出る）。このため、残った（能力の衰えた）右目の時を薬で戻して、能力を取り戻すことを考えていると読める
- 関連: 人物 [羽田浩司](../characters.md#C-haneda-koji)、[アマンダ・ヒューズ](../characters.md#C-amanda-hughes)、[ラム](../characters.md#C-rum)／考察 Q-009／知識表 [K4-3](../knowledge-matrix/04-haneda-case.md)
