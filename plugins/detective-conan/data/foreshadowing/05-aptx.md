### F-APTX-001 APTX4869 はもともと何のために作られた薬なのか

- 経過: 毒薬として使われているが、本来の目的は別にあると示される
- 回収: —

- 関連: 人物 [宮野志保](../characters.md#C-miyano-shiho)、[宮野厚司](../characters.md#C-miyano-atsushi)、[宮野エレーナ](../characters.md#C-miyano-elena)／考察 Q-005

### F-APTX-002 「シルバーブレット」とは何か
- 状態: 部分回収
- 重要度: ★★
- 区分: [原作]
- 初出: 原作 File 430「血塗られた幽霊船」（42巻「黒の組織と真っ向勝負満月の夜の二元ミステリー」）— カクテル名として出る
- 経過: 原作 File 434「ラットゥンアップル」（42巻「黒の組織と真っ向勝負満月の夜の二元ミステリー」）— あだ名として出る。ベルモットがジンに「あの方は赤井をシルバーブレットと恐れている」と話し、コナン（新一）もシルバーブレットと見なされる
- 回収: 原作 File 821「ミステリートレイン［交差］」（78巻「漆黒の特急［ミステリートレイン］［発車／隧道／交差／終点］」）— エレーナが18歳の志保に残したテープで、宮野夫妻が研究中の薬を「シルバーブレット」と呼んでいたことが判明する
- 内容: 組織を倒す「銀の弾丸」という言葉と、宮野夫妻の研究の呼び名の関係
- 関連: 人物 [宮野厚司](../characters.md#C-miyano-atsushi)、[宮野エレーナ](../characters.md#C-miyano-elena)、[赤井秀一](../characters.md#C-akai-shuichi)、[工藤新一](../characters.md#C-kudo-shinichi)、[ベルモット](../characters.md#C-vermouth)／考察 Q-005

### F-APTX-003 宮野夫妻はなぜ死んだのか
- 状態: 部分回収
- 重要度: ★★
- 区分: [原作]
- 初出: 原作 File 179「偽りの少女」（18巻「黒の組織から来た女大学教授殺人事件［2］」）— 灰原が「両親は私が幼い頃、研究所の事故で死んだ」と話す
- 経過: File 242「白の世界」（24巻「黒の組織との再会」）— ピスコが「事故で死んだ両親」と言う／File 384「意外なお宝」（38巻「夕陽に染まった雛人形」）— 灰原が「組織は研究所の事故と言っている」と、組織の説明を疑う／File 939「デパートでランチ！」（89巻「探偵団はヤブの中」）— 灰原が「母は私が生まれて間もなく死んだ」と話す
- 回収: 原作 File 948「握られたハサミ」（89巻「17年前と同じ現場」）— 研究所の火災による焼死で、資料の多くも焼けたと具体的に語られる。組織は「事故」と説明しているが、本当の経緯（火災の原因）は未回収。テープの内容から、エレーナは死を予期していたとみられる
- 内容: 志保と明美の両親が死んだ経緯
- 関連: 人物 [宮野厚司](../characters.md#C-miyano-atsushi)、[宮野エレーナ](../characters.md#C-miyano-elena)／考察 Q-006

### F-APTX-004 宮野エレーナが志保に残したテープには何が込められているのか
- 状態: 部分回収
- 重要度: ★★
- 区分: [原作]
- 初出: 原作 File 425「隠されていた真実」（42巻「トイレに隠した秘密」）— 明美がトイレのタンクに隠していたテープをコナンが回収する。灰原が聞く冒頭は「11歳になった志保へ…誕生日おめでとう」
- 経過: 原作 File 427「蘭の推理」（42巻「コンビニの落とし穴」）— 18歳用のメッセージ「後悔しない？…私は味方よ」
- 回収: 原作 File 821「ミステリートレイン［交差］」（78巻「漆黒の特急［ミステリートレイン］［発車／隧道／交差／終点］」）— その続き。「とても恐ろしい薬を作っている／仲間は夢の薬と言う／パパと願いを込めてシルバーブレットと呼んでいる／完成には志保とお姉ちゃんと別れなければならない」。誕生日ごと、複数年分のメッセージが残されている（本数は資料により4本／20本で食い違いがあり要確認）
- 内容: エレーナが誕生日ごとに聞けるように残したテープの中身と、その中の研究への言及
- 関連: 人物 [宮野エレーナ](../characters.md#C-miyano-elena)、[宮野志保](../characters.md#C-miyano-shiho)／考察 Q-005、Q-006

### F-APTX-005 宮野エレーナが「ヘルエンジェル」と呼ばれたのはなぜか
- 状態: 部分回収
- 重要度: ★
- 区分: [原作]
- 初出: 原作 File 424「小さな密室に残された秘密」（41巻「トイレに隠した秘密」）— 灰原が「組織で母はヘルエンジェル…地獄に堕ちた天使と呼ばれていた」と話す。由来は作中で説明されておらず、灰原の訳「地獄に堕ちた天使」があるだけ（優しい人柄からという説はファンの推測）。File 425「隠されていた真実」（42巻「トイレに隠した秘密」）の最後でコナンが「お前の母さんは正真正銘のエンジェル」と心の中でつぶやく
- 経過: File 1009–1012（95巻「迷宮カクテル」）— 幼い降谷零が町医者のエレーナに手当てしてもらっていた回想。降谷・若狭（File 1070「こんな所で会えるとは…」（101巻「宮野明美のタイムカプセル」））もこの呼び名を使う
- 回収: 由来は原作で明かされていない（未回収のまま）
- 内容: エレーナの呼び名の由来と人柄
- 関連: 人物 [宮野エレーナ](../characters.md#C-miyano-elena)、[降谷零](../characters.md#C-furuya-rei)／考察 Q-006

### F-APTX-011 第26作で老若認証システムは灰原の正体を組織にさらしたか
- 状態: 回収済
- 重要度: ★★★
- 区分: [劇場版]
- 初出: 劇場版第26作『黒鉄の魚影』（2023）
- 経過: 組織がシェリー生存を示す写真を手に入れ、ジンが灰原の拉致を命じる。ピンガがグレースとしてパシフィック・ブイに潜入
- 回収: 劇場版第26作 — ピンガは老若認証システムでコナン＝新一の正体にも気づいたが、白鳥・佐藤の到着で捕獲を諦めて逃走しそのまま死亡（組織には伝わっていない）。最終的にベルモットが老若認証システムを「欠陥」と報告し、ラムがパシフィック・ブイの破壊を命じてシェリー生存の疑いは消えた
- 内容: 年齢を超えて顔を照合する技術で灰原＝志保が組織に知られる危機の経緯
- 関連: 人物 [宮野志保](../characters.md#C-miyano-shiho)、[直美・アルジェント](../characters.md#C-naomi-argento)、[ピンガ](../characters.md#C-pinga)、[ベルモット](../characters.md#C-vermouth)、[ラム](../characters.md#C-rum)、[ジン](../characters.md#C-gin)／伏線 [F-APTX-008](#F-APTX-008)／知識表 [K2](../knowledge-matrix/02-haibara-aptx.md)
- 備考: 直美・アルジェントは小学生の頃に志保と知り合っていた
