### F-AKAI-004 「領域外の妹」は誰か
- 状態: 回収済
- 重要度: ★★
- 区分: [原作]
- 初出: 原作 File 875（83巻「赤の悲劇」赤い女の惨劇）— 世良のスマホの待ち受け写真に写った少女として初めて出る。原作 File 876–878（83巻「意外な結果の恋愛小説」）— 本人が動いて登場し、File 878 で世良自身が「領域外の妹」という呼び名を指示する
- 経過: キールが杯戸中央病院に「赤井の妹」を偽って入院したという言及があり、これが File 875 より前の伏線である可能性がある（該当 File は要確認）
- 回収: 原作 File 953（90巻「暗がりに鬼を繋ぐが如く」霊魂探偵殺害事件）— 世良が少女を「ママ」と呼び、世良の母だとわかる。原作 File 972–974（92巻「さざ波の魔法使い」）— 10 年前の回想で、大人のメアリーが三兄妹の母として描かれ、File 974 の最後でコナンが「あの子がメアリーで、縮んでいる」と気づく
- 内容: 世良の周りにいる、顔を見せない少女の素性
- 関連: 人物 [赤井メアリー](../characters.md#C-akai-mary)、[世良真純](../characters.md#C-sera-masumi)／考察 Q-014／知識表 [K3-1](../knowledge-matrix/03-akai-family.md)

### F-AKAI-009 羽田秀吉は何者か

- 初出: 原作 File 847（80巻）「現場の隣人は元カレ」— 由美の元恋人として登場
