### F-KUDO-003 服部平次はどうやってコナンの正体に気づいたのか
- 状態: 回収済
- 重要度: ★
- 区分: [原作]
- 初出: 原作 File 92（10巻）「外交官殺人事件」— 平次が初登場し、新一に会う
- 経過: File 117–120（12・13巻「ホームズ・フリーク殺人事件」）で、平次が蘭に「親父さんが推理する時、あのボウズはどこにおる？」と尋ね、疑い始める
- 回収: 原作 File 121（13巻「本当の姿」）— 麻酔銃で眠らされた平次が、小五郎に殴られたショックで目を覚まし、コナンが自分の声で推理しているのを目撃して確信する。その後コナンに詰め寄り、「蘭にばらす」と迫って白状させる
- 内容: 平次が正体を知った経緯
- 関連: 人物 [服部平次](../characters.md#C-hattori-heiji)／知識表 [K1-1](../knowledge-matrix/01-conan-shinichi.md)

### F-KUDO-005 第13作でアイリッシュはコナンの正体をどこまで把握したか
- 状態: 回収済
- 重要度: ★★
- 区分: [劇場版]
- 初出: 劇場版第13作『漆黒の追跡者』（2009）
- 経過: —
- 回収: 劇場版第13作 — アイリッシュは独自の調査でコナン＝工藤新一だと突き止め、東都タワーで本人に告げた。ピスコの件でジンを恨んでおり「誰にも言っていない」と語る。ジンの命令によるキャンティの狙撃でNOCリストのメモリーカードごと撃たれ、コナンをかばって死亡。**組織には伝わっていない**（本人が誰にも言わないまま死亡）
- 内容: 組織の構成員が劇場版でコナンの正体に気づいた経緯と、その後
- 関連: 人物 [アイリッシュ](../characters.md#C-irish)、[ジン](../characters.md#C-gin)／伏線 [F-KUDO-004](#F-KUDO-004)／知識表 [K1-1](../knowledge-matrix/01-conan-shinichi.md)
