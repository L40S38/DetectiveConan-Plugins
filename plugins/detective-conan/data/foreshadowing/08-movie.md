# 伏線リスト：劇場版

[← 伏線一覧に戻る](README.md)

劇場版の描写は原作の正史とは別扱い。ここでは「その作品で何が描かれたか」を記録する。

- 回収: 劇場版第 5 作 — 組織の構成員が灰原を見かけるが、正体は確かめられない（要確認：細部）
- 内容: 劇場版で初めて組織と灰原が接近した作品
- 関連: 人物 [宮野志保](../characters.md#C-miyano-shiho)、[ジン](../characters.md#C-gin)

<a id="F-MOVIE-002"></a>
### F-MOVIE-002 漆黒の追跡者：アイリッシュはコナンの正体にどこまで迫ったのか
- 状態: 回収済
- 重要度: ★★
- 区分: [劇場版]
- 初出: 劇場版第 13 作『漆黒の追跡者』（2009）
- 経過: —
- 回収: 劇場版第 13 作 — アイリッシュは独自の調査でコナン＝工藤新一だと突き止め、東都タワーで本人に告げる（コナンもアイリッシュが知っていることを把握している）。ピスコの件でジンを恨んでおり、誰にも言っていないと語る。ジンの命令によるキャンティの狙撃で、NOC リストの入ったメモリーカードごと撃たれ、コナンをかばって死亡。**組織には伝わっていない**（本人が誰にも言わなかったまま死亡。有力：劇場版第26作の時点でもジンはコナン・灰原の正体を知らないとされる）
- 内容: 組織の構成員が劇場版でコナンの正体に近づいた件
- 関連: 人物 [アイリッシュ](../characters.md#C-irish)、[ジン](../characters.md#C-gin)／知識表 [K1-1](../knowledge-matrix/01-conan-shinichi.md)

<a id="F-MOVIE-003"></a>
### F-MOVIE-003 純黒の悪夢：NOC リストは組織の手に渡ったのか
- 状態: 回収済
- 重要度: ★★
- 区分: [劇場版]
- 初出: 劇場版第 20 作『純黒の悪夢』（2016）
- 経過: —
- 回収: 劇場版第 20 作 — **一部だけが組織に伝わった**。キュラソーが逃走中に送ったメールで、スタウト（MI6）・アクアビット（CSIS）・リースリング（BND）の3人が伝わり、3人とも処刑された。同じメールの続き（「あなたが気にしていたバーボンとキール…」）は途中で途切れる。コナンがキュラソーを装って「バーボンとキールは関係なかった」という偽メールを送り、ラムの指示で2人の処刑は中止された。キュラソー本人が記憶していた残りの情報は、観覧車を止める際に死亡し失われた
- 内容: 各国の潜入捜査官の名簿をめぐる事件
- 関連: 人物 [キュラソー](../characters.md#C-curacao)、[ラム](../characters.md#C-rum)、[降谷零](../characters.md#C-furuya-rei)、[本堂瑛海](../characters.md#C-hondo-hidemi)／考察 Q-025

<a id="F-MOVIE-004"></a>
### F-MOVIE-004 ハロウィンの花嫁：警察学校組が関わった過去の事件とは何か
- 状態: 回収済
- 重要度: ★★
- 区分: [劇場版]
- 初出: 劇場版第 25 作『ハロウィンの花嫁』（2022）
- 経過: —
- 回収: 劇場版第 25 作 — 3年前の11月6日、降谷・松田・伊達・諸伏の4人が萩原研二（7年前の11月7日に殉職）の墓参りの帰りに、仮面の爆弾犯（プラーミャ）に遭遇。松田が爆弾を解体し、降谷と諸伏が犯人の右肩を撃ち抜くが取り逃がす。その翌日、松田は観覧車の爆弾で殉職した。本編ではプラーミャが降谷に首輪爆弾を付け、降谷はその特徴から同一人物だと見抜く。終盤でコナンが爆弾を止めた方法は、新一が小学4年生の時に出会った萩原研二から学んだものだとエピローグで明かされる
- 内容: 警察学校組の過去の事件
- 関連: 人物 [降谷零](../characters.md#C-furuya-rei)、[松田陣平](../characters.md#C-matsuda-jinpei)、[萩原研二](../characters.md#C-hagiwara-kenji)、[伊達航](../characters.md#C-date-wataru)、[諸伏景光](../characters.md#C-morofushi-hiromitsu)

### F-MOVIE-005 黒鉄の魚影：老若認証で灰原の正体は暴かれるのか
- 状態: 回収済
- 重要度: ★★★
- 区分: [劇場版]
- 初出: 劇場版第 26 作『黒鉄の魚影』（2023）
- 経過: 組織がシェリー生存を示す写真を手に入れ、ジンが灰原の拉致を命じる。ピンガがグレースとしてパシフィック・ブイに潜入
- 回収: 劇場版第 26 作 — ピンガは老若認証システムでコナン＝新一の正体にも気づいたが、白鳥・佐藤の到着で捕獲を諦めて逃走し、そのまま爆破処分予定の潜水艦に戻って死亡（組織には伝わっていない）。最終的にベルモットが老若認証システムを「欠陥」と報告し、ラムがパシフィック・ブイの破壊を命じて、シェリー生存の疑いは消えた
- 内容: 年齢を超えて顔を照合する技術で灰原＝志保が組織に知られるのか
- 関連: 人物 [宮野志保](../characters.md#C-miyano-shiho)、[直美・アルジェント](../characters.md#C-naomi-argento)、[ピンガ](../characters.md#C-pinga)、[ベルモット](../characters.md#C-vermouth)、[ラム](../characters.md#C-rum)、[ジン](../characters.md#C-gin)／知識表 [K2](../knowledge-matrix/02-haibara-aptx.md)
- 備考: 直美・アルジェントは小学生の頃に志保と知り合っていた
