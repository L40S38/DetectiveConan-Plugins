### F-REL-001 蘭はコナン＝新一だと気づくのか
- 状態: 未回収
- 重要度: ★★★
- 区分: [原作]
- 初出: 原作 File 26–29（3巻「月いちプレゼント脅迫事件」）— 蘭がコナンにかまをかけて疑うが、阿笠が変声機で新一として電話をかけて晴らす
- 経過: 何度も疑っては否定されている。主な場面：
  - 原作 File 131–133（14巻「追いつめられた名探偵！連続2大殺人事件［1］」）— 眼鏡を外したコナンの顔を見た蘭が、幼い頃の新一に瓜二つだと気づき、アルバムの幼い新一の写真で疑いを強める。そこへ工藤有希子が現れ、コナンを親戚の子だと説明して疑惑を晴らす（要確認：有希子が現れる File）。
  - 原作 File 251–253（25巻「命がけの復活［洞窟の探偵団／負傷した名探偵］」）— コナンが洞窟で負傷し輸血が必要になった際、蘭がコナンの血液型が新一と同じだと気づき、疑惑を深める。File 253「一つの確信」（25巻「命がけの復活［洞窟の探偵団／負傷した名探偵］」）で、蘭はコナン＝新一だと確信するに至る。
  - 原作 File 254–257（26巻「命がけの復活［第三の選択／黒衣の騎士］」）— 解毒剤（白乾児）を飲んで新一に戻ったコナンが蘭と再会する。File 256–257（26巻「命がけの復活［第三の選択／黒衣の騎士］」）で新一とコナン（灰原の変装）が同時に現れ、蘭の疑惑は晴れる。
  - 原作 File 479–483（46・47巻「奇妙な一家の依頼疑惑を持った蘭」）— 蘭が新一宛メールをコナンの携帯に送信してしまい、コナン＝新一の疑惑が強まる。コナンは本物の携帯をバケツに隠して阿笠博士の携帯とすり替え、変声機で「新一」として蘭に電話をかけてごまかす。
  - 原作 File 646–651（62巻「殺人犯、工藤新一／新一の正体に蘭の涙」）（要確認：この回での蘭の疑い方）
  - 原作 File 693–695（66巻「恥ずかしいお守りの行方」）— 和葉のお守りに入っている手錠の鎖に、コナンしか触っていないはずなのに新一の指紋があることに蘭が気づき、コナン＝新一の疑惑がさらに深まる。
  - 原作 File 812–814（77巻「工藤優作の未解決事件［コールド・ケース］」）— コナンが謎解きを説明するうちに、蘭は「新一が話しているようだ」と感じて手を止める。コナンは「新一のメールを読んでいただけ」と誤魔化す。
  - 原作 File 1023–1024（96巻「代役・京極真」）— 世良真純にコナンが新一ではないかと問われた蘭が否定する（新一との交際が始まった後のこと）。
- 回収: —
- 内容: 蘭がコナンの正体を知る日が来るのか
- 関連: 人物 [毛利蘭](../characters.md#C-mori-ran)、[工藤新一](../characters.md#C-kudo-shinichi)／考察 Q-018／知識表 [K1-1](../knowledge-matrix/01-conan-shinichi.md)／恋愛関係 [loves.md A](../relationships/loves.md)
