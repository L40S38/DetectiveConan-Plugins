### F-KID-006 怪盗キッドはコナンの正体を知っているのか
- 状態: 回収済
- 重要度: ★
- 区分: [原作]
- 初出: 原作 File 156「邂逅」（16巻「コナンVS怪盗キッド」）
- 経過: キッドはコナンを「名探偵」と呼び、新一に変装する場面がある／File 731–733（70巻「コナンキッドの龍馬お宝攻防戦」）でコナンが自分の母（有希子）の話をし、キッドも自分の母が怪盗淑女だとほのめかす／File 963–965（91巻「怪盗キッドの絡繰箱」）で、阿笠博士に化けたキッドが二人きりのときにコナンを「コナン君」と呼び、本物の博士なら二人きりでは「新一」と呼ぶことから見破られる／原作 File 1119–1122（105巻「キッドVS白馬青の玉座（アズール・スローン）」）、特に File 1120「代役」（105巻「キッドVS白馬青の玉座（アズール・スローン）」）— 殺人の濡れ衣を着せられかけたキッドがコナンに助けを求め、コナンは工藤新一になりきることを条件に引き受けて、蝶ネクタイでキッドに推理を伝える。そのやりとりの中で、コナンがどうして自分に顔が似ているのかと突っ込み、キッドは先祖が同じなのではないかと軽く返す（要確認：台詞の正確な文言。速報・感想サイトで表記が割れる）
- 回収: 原作 File 1018「氷中」（96巻「キッドＶＳ高明狙われた唇」）— コナン・服部平次・諸伏高明がそろった鈴木大博物館で、キッドは、高校生探偵が 2 人と、長野の軍師のような刑事がいるのを見て、その夜の盗みを見送ると独白する（要確認：台詞の文言）。キッドはコナンを高校生探偵の一人に数えており、原作でも、この時点でキッドはコナンの正体を知っていたことになる。原作で、キッドがいつ正体を知ったかは描かれていない。[劇場版] 第3作『世紀末の魔術師』では、白鳥任三郎に変装していたキッドが、コナンと阿笠博士の電話を盗み聞きして、コナンが工藤新一だと知る。[ファン説] 劇場版で描かれたこの設定が、のちに原作にも少しずつ取り込まれたとする見方がある
- 内容: キッドはコナンの正体に気づいているのか
- 関連: 人物 [黒羽快斗](../characters.md#C-kuroba-kaito)／知識表 [K1-1](../knowledge-matrix/01-conan-shinichi.md)
