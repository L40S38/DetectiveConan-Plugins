### F-KID-006 怪盗キッドはコナンの正体を知っているのか
- 状態: 部分回収
- 重要度: ★
- 区分: [原作]
- 初出: 原作 File 156（16巻）「コナンVS怪盗キッド」
- 経過: キッドはコナンを「名探偵」と呼び、新一に変装する場面がある／File 731–733（70巻「コナンキッドの龍馬お宝攻防戦」）でコナンが自分の母（有希子）の話をし、キッドも自分の母が怪盗淑女だとほのめかす
- 回収: 原作 File 1119–1122（105巻「キッドVS白馬 青の玉座」）、特に File 1120「代役」— コナンがキッドを見逃す条件として新一の代役を頼み、蝶ネクタイでキッドと口裏を合わせる。コナンが「オレに似すぎ」と言うと、キッドが「先祖が同じなんじゃねーの」と返す。原作に明言の台詞はないが、コナン側もキッドが知っている前提で行動しており、有力な描写
- 内容: キッドはコナンの正体に気づいているのか
- 関連: 人物 [黒羽快斗](../characters.md#C-kuroba-kaito)／知識表 [K1-1](../knowledge-matrix/01-conan-shinichi.md)
