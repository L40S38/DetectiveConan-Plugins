### F-POL-003 「ゼロ」とは何を指すのか
- 状態: 回収済
- 重要度: ★
- 区分: [原作]
- 初出: 原作 File 888–890（84巻「ギスギスしたお茶会」）付近 — 病院で「ゼロ」という声に安室が反応し、子どもの頃のあだ名だとごまかす（「透→透ける→ゼロ」）
- 経過: 原作 File 897「緋色の真相」（85巻「緋色シリーズ［交錯／帰還／真相］」）— 赤井が「あだ名が『ゼロ』だとあのボウヤに漏らしたのは失敗だったな…」と、あだ名と本名「降谷零」を結び付けて呼ぶ
- 回収: あだ名であることは File 888–890（84巻「ギスギスしたお茶会」）〜File 894–897（85巻「緋色シリーズ［交錯／帰還／真相］」）で確定。**「警察庁警備局警備企画課の通称」だと原作で明言された箇所は見つかっていない**（要確認。出典は劇場版第20作の小説版・第22作、作者のポストカード回答〔2016〕にとどまる）
- 内容: 作中で「ゼロ」と呼ばれるものの意味
- 関連: 人物 [降谷零](../characters.md#C-furuya-rei)／知識表 [K6-3](../knowledge-matrix/06-police.md)

### F-POL-004 スコッチはなぜ死んだのか
- 状態: 回収済
- 重要度: ★★
- 区分: [原作]
- 初出: 原作 File 936「ガールズバンド」（88巻「仲の悪いガールズバンド」）— 「スコッチ」の名前が出る
- 経過: —
- 回収: 原作 File 954「裏切りの制裁」（90巻「裏切りのステージ」）— 安室の回想。屋上でスコッチのそばに拳銃を持った赤井がおり、「裏切りには制裁を」と言う。原作 File 957「裏切りの真相」（90巻「裏切りのステージ」）— 真相が描かれる。正体が露見したスコッチは赤井の拳銃を奪い、胸ポケットの携帯ごと自分を撃とうとする。赤井はシリンダーを押さえて FBI だと明かし、逃がそうとするが、近づく足音（実は降谷）を組織の追っ手と思い込んだスコッチが自ら命を絶つ
- 内容: 組織にいたスコッチが死んだ経緯
- 関連: 人物 [諸伏景光](../characters.md#C-morofushi-hiromitsu)、[赤井秀一](../characters.md#C-akai-shuichi)、[降谷零](../characters.md#C-furuya-rei)／知識表 [K6-4](../knowledge-matrix/06-police.md)、[K6-5](../knowledge-matrix/06-police.md)
- 備考: 誰がどうやってスコッチの潜入を組織に密告したかは、作中で描かれていない（Q-025 と関連）

### F-POL-005 安室透はなぜ赤井秀一を憎んでいるのか

- 区分: [原作]
- 初出: 原作 File 703「吹雪の中の真実」（67巻「黒き13の暗示［サジェスト］／迫る黒の刻限［タイムリミット］／赤く揺れる照準［ターゲット］」）— ウォッカの台詞で、バーボンがジン以上に赤井を嫌っていると示される
- 経過: 原作 File 897–898（85巻「緋色シリーズ［交錯／帰還／真相］」）— 赤井が「彼の事は今でも悪かったと思っている」と言い、恨みの深さが示される。File 937「消された手がかり」（88巻「仲の悪いガールズバンド」）— 安室が、スコッチは赤井のせいで死んだと心の中で考える

- 内容: 安室と赤井の確執の原因
- 関連: 人物 [降谷零](../characters.md#C-furuya-rei)、[赤井秀一](../characters.md#C-akai-shuichi)、[諸伏景光](../characters.md#C-morofushi-hiromitsu)／考察 Q-020

### F-POL-009 伊織無我は執事になる前に何をしていたのか
- 状態: 部分回収
- 重要度: ★★
- 区分: [原作]
- 初出: 原作 File 981「喫茶ポアロで暇潰し」（92巻「謎解きは喫茶ポアロで」）— 喫茶ポアロに百人一首を詠む謎の客として現れる。安室透が同席していた
- 経過: 大岡紅葉の執事として登場を重ねる（File 1039–1042（98巻「大岡紅葉の挑戦状」）など）／File 1088–1090（102巻「大岡紅葉の甘い罠」）で、喫茶ポアロの回（File 981–983（92・93巻「謎解きは喫茶ポアロで」））に伊織が変装して安室透に会いに行っていたことがわかる。同じ File で、伊織が公安時代の潜入捜査で使っていた偽名「榊原」も明らかになる
- 回収: 原作 File 1113–1115（104・105巻「執事になった理由」）— 伊織は元公安警察官だった。「元公安の伊織」と知る人物に脅され、3 年前の公安警察官時代の出来事を回想する。公安時代に何があり、なぜ辞めて大岡家の執事になったかの全容は要確認
- 内容: 大岡家の執事・伊織無我の前歴と、執事になった理由
- 関連: 人物 [伊織無我](../characters.md#C-iori-muga)、[大岡紅葉](../characters.md#C-ooka-momiji)、[降谷零](../characters.md#C-furuya-rei)、[黒田兵衛](../characters.md#C-kuroda-hyoe)／考察 Q-025、Q-026／知識表 [K6](../knowledge-matrix/06-police.md)
- 備考: 伊織は安室を公安の人間と認識しているとみられる（知識表 K6-2、K6-3）。黒田兵衛は大岡家に立ち寄る間柄（File 1088–1090（102巻「大岡紅葉の甘い罠」））
