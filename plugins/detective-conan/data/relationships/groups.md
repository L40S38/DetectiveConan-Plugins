# グループ・組織

少年探偵団・毛利事務所・警察・FBI・黒ずくめの組織など、何人かがまとまって動くグループを記録する。
家族・きょうだいは `families.md`、友人・ライバル関係は `friends-and-rivals.md`、恋愛関係は `loves.md` に記録する。
記号・更新手順は `README.md` および `conventions.md` の「9. relationships/ の記入規則」を参照。

### 少年探偵団 `G-shonen-tantei`

**状態**: ◎ 活動中  
**構成員**: 江戸川コナン `C-kudo-shinichi`、小嶋元太 `C-kojima-genta`、円谷光彦 `C-tsuburaya-mitsuhiko`、吉田歩美 `C-yoshida-ayumi`、灰原哀 `C-miyano-shiho`

#### 経緯

- コナン（原作 File 1「平成のホームズ」（1巻「ジェットコースター殺人事件」）・File 2「小さくなった名探偵」（1巻「社長令嬢誘拐事件」）初登場）が帝丹小に転入後、歩美・元太・光彦と自然に行動をともにするようになった。
- 灰原哀（原作 File 176「転校生は…」（18巻「黒の組織から来た女大学教授殺人事件［1］」）初登場）が後に班に加わる。歩美・光彦・元太は灰原の正体を知らない（知識表 K2）。[公式発言]『週刊少年サンデー』2013 年 33 号付録（83 巻にも収録）で、作者は、歩美・光彦・元太の 3 人は灰原を潜り込ませるために考えたキャラクターだと語っている（日本語版 Wikipedia・D の 1 サイトによる孫引き。要確認：誌面そのもの）。
- 吉田歩美（原作 File 17「恐怖の館」（2巻「幽霊屋敷殺人事件」）初登場）はコナンに好意を寄せている（→ loves.md の「吉田歩美 → 江戸川コナン」を参照）。探偵団の中で灰原が名前で呼ぶことを許したのは歩美だけで、灰原の側は歩美を「吉田さん」と呼ぶ。
- 原作 File 176–178（18巻「黒の組織から来た女大学教授殺人事件［1］」）— 帝丹小学校 1 年 B 組に転校生が来る。転校生の名字が「灰原」だとクラスに伝えたのは歩美で、放課後、歩美は光彦と一緒に灰原を少年探偵団に誘う。
- 原作 File 200–203（20・21巻「青の古城探索事件」）— コナンが行方不明になって泣く歩美に、灰原は、コナンは自分で戻ってくると取り合わない。どうしてそんなにコナンのことがわかるのかと思った歩美は、コナンのことが好きなのかと灰原に尋ね、灰原はコナンをそういう対象として見ていないと答える（File 201「そしてまた…」（21巻「青の古城探索事件」））。そのあと灰原は、焼けた塔を調べに行く間、隠れて待つよう歩美に言いつけるが、歩美は言いつけを破って塔に入り、追ってきた何者かから灰原にかくまわれて叱られる。
- 原作 File 238–242（24巻「黒の組織との再会」）— 組織におびえてとげとげしくなった灰原を見て、歩美・光彦・元太は、灰原がいじめられているのではないかと心配する。
- 原作 File 398–400（39巻「お金で買えない友情」）— 歩美は、友達はみな「ちゃん」付けで呼んでいるのに、灰原だけを「灰原さん」と呼んでいることに気づき、キャンプの間、何度も「哀ちゃん」と呼ぼうとして言いよどむ。帰りの車で歩美の思いに気づいた灰原は、「哀ちゃん」と呼ぶことを許すが、まねをした光彦と元太には許さない（File 400「引き裂かれた友情［3］」（39巻「お金で買えない友情」））。灰原の側は、その後も歩美を「吉田さん」と呼んでいる。
- 原作 File 435–437（42・43巻「お尻のマークを探せ」）— ベルモットとの対決のあと、FBI のジョディは灰原に、証人保護プログラムを受けてコナンたちと別れ、別人として生きるよう勧める。逃げてばかりでは勝てない、自分は逃げたくない、という歩美の言葉に心を動かされた灰原は、プログラムを断り、少年探偵団にとどまる（原作 File 437「灰原哀の決意」（43巻「お尻のマークを探せ」））。
- 原作 File 775–777（74巻「博士の動画サイト」）— 阿笠邸でカレーを作っている最中、元太が部屋で蹴ったボールが鍋に入り、歩美がカレーをかぶる。怒った灰原は元太に平手打ちをする（日本語版 Wikipedia・D の 1 サイト）。風呂を借りて灰原の服に着替えた歩美は、留守番の間に連れ去られ、コナンたちに助け出される（要確認：服の細部は英語の出典のみ）。
- 原作 File 815–817（77巻「灰原の秘密に迫る影」）— 少年探偵団のキャンプへ向かう車の中で、コナンは灰原が解毒剤を持ち歩いていることを知る。少年探偵団の子どもたちと山小屋に閉じ込められて火事になったとき、灰原はその解毒剤を自分で飲んで宮野志保の姿に戻り、正体を明かさないまま子どもたちを助け出す。このときの出来事を光彦がビデオに撮っており、それがもとで、シェリーがベルツリー急行に乗ることが組織に知られる（原作 File 818–824（78巻「漆黒の特急［ミステリートレイン］［発車／隧道／交差／終点］」）。→ friends-and-rivals.md の「コナン × 灰原哀」「灰原哀 × ベルモット」を参照）。
- 原作 File 939–941（89巻「探偵団はヤブの中」）— デパートの化粧品売り場で、灰原は歩美と一緒にメイクをしてもらう。母親のことを聞かれた灰原は、母は自分が生まれてすぐに死んだと答える（F-APTX-003 の経過）。
- 原作 File 1163–1166（109・110巻「命懸けのイタズラゲーム」）— 若狭先生と親しげに話す灰原を見て、歩美たちは、灰原は本当に若狭先生が好きなのだと納得する（→ friends-and-rivals.md の「灰原哀 × 若狭留美」を参照）。強盗団に閉じ込められた原作 File 1165「孤独な殺意」（110巻「命懸けのイタズラゲーム」）では、組織から逃げた直後は復讐のためにコナンや博士を利用するつもりだった灰原が、少年探偵団と過ごすうちに変わっていったことが回想で描かれる（D の複数サイト）。回想には、原作 File 437「灰原哀の決意」（43巻「お尻のマークを探せ」）の歩美の言葉や、原作 File 201「そしてまた…」（21巻「青の古城探索事件」）の歩美とのやりとりの場面も描き直されている。反撃を前に、コナンは自分がなんとかしてやると少年探偵団を励ます（→ friends-and-rivals.md の「コナン × 灰原哀」を参照）。
- [アニオリ] アニメ第140話「SOS! 歩美からのメッセージ」— 灰原が歩美を「歩美ちゃん」と呼ぶ（日本語版 Wikipedia。原作では「吉田さん」）。
