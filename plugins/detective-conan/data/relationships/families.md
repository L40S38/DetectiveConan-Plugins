### 工藤家 `G-kudo-family`

**構成員**: 工藤優作 `C-kudo-yusaku`、工藤有希子 `C-kudo-yukiko`、工藤新一 `C-kudo-shinichi`

#### 経緯

- 工藤優作・工藤有希子（原作 File 49「見知らぬ来訪者。」（5巻「江戸川コナン誘拐事件」）初登場）。工藤新一は原作 File 1「平成のホームズ」（1巻「ジェットコースター殺人事件」）初登場。
- 優作は世界的な推理小説家兼探偵。有希子は元女優で変装の名手。有希子は女優時代、シャロン・ヴィンヤード（ベルモット）と同じ時期に黒羽盗一から変装術を習った（F-KID-002 回収済）。
- 新一が APTX4869 を飲まされ縮んだ後、両親は渡航先に留まりしばらく日本を離れた。後に工藤邸に戻り、赤井秀一（沖矢昴）を居候させて情報共有を続けた（F-AKAI-002 回収済）。
- 優作は組織の動向を早くから把握しており、原作 File 1008「ホラ」（95巻「マリアちゃんをさがせ！」）で赤井とともに「PUT ON MASCARA」の文字を「CARASUMA（烏丸）」と読み解いた。

### 羽田家 `G-haneda-family`

**構成員**: 羽田康晴 `C-haneda-yasuharu`（秀吉の養父）、羽田市代 `C-haneda-ichiyo`（浩司の母・秀吉の養母）、羽田浩司 `C-haneda-koji`（故人）、羽田秀吉 `C-haneda-shukichi`（養子・赤井家次男）

#### 経緯

- 羽田秀吉は赤井家の次男として生まれ、「羽田家」の養子となった。秀吉が羽田家の養子で、羽田浩司が義兄にあたることは原作 File 948–950（89・90巻「17年前と同じ現場」）でわかる（F-RUM-007 回収済）。赤井家の生まれであることは、原作 File 945–947（89巻「婚姻届のパスワード」）で、婚姻届の父欄に「赤井務武」とあることから確定する（F-AKAI-009 回収済）。[原作] 母欄は、原作 File 947「座右の銘」（89巻「婚姻届のパスワード」）の婚姻届では一部しか見えず「…世良」と読める程度で、「メアリー世良」とはっきり読めるのはアニメ第 849–850 話「婚姻届のパスワード」（この事件をアニメ化した原作回）。
- 義兄・羽田浩司（原作 File 948「握られたハサミ」（89巻「17年前と同じ現場」）初登場＝回想）は将棋の棋士（四冠王）で、17年前にラムに「組織が開発した毒薬」を飲まされて死亡した（F-RUM-003、F-RUM-006）。死の直前、御守りの角行を浅香（後の若狭留美）に託し、母からもらった手鏡をハサミで切って「CARASUMA」を示すメッセージを残した（F-RUM-004 部分回収、原作 File 1107–1108（104巻「17年前の真相［遠見の角行／女王の謀（クイーンズ・ギャンビット）］」））。
- 秀吉は棋士として名人を目指し続けており、義兄の死の謎が徐々に解明されていくにつれ、羽田浩司事件の関係者とも繋がっていく。
