### 工藤家 `G-kudo-family`

**構成員**: 工藤優作 `C-kudo-yusaku`、工藤有希子 `C-kudo-yukiko`、工藤新一 `C-kudo-shinichi`

#### 経緯
- 工藤優作・工藤有希子（原作 File 49「見知らぬ来訪者。」（5巻「江戸川コナン誘拐事件」）初登場）。工藤新一は原作 File 1「平成のホームズ」（1巻「ジェットコースター殺人事件」）初登場。
- 優作は世界的な推理小説家兼探偵。有希子は元女優で変装の名手。有希子は女優時代、シャロン・ヴィンヤード（ベルモット）と同じ時期に黒羽盗一から変装術を習った（F-KID-002 回収済）。
- 新一が APTX4869 を飲まされ縮んだ後、両親は渡航先に留まりしばらく日本を離れた。後に工藤邸に戻り、赤井秀一（沖矢昴）を居候させて情報共有を続けた（F-AKAI-002 回収済）。
- 優作は組織の動向を早くから把握しており、原作 File 1008「ホラ」（95巻「マリアちゃんをさがせ！」）で赤井とともに「PUT ON MASCARA」の文字を「CARASUMA（烏丸）」と読み解いた。
