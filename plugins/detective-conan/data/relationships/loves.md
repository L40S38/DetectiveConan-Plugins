- 原作 File 350–354（34・35巻「工藤新一NY［ニューヨーク］の事件」）— NYでブロードウェイを観劇していた蘭・新一・有希子が、連続殺人事件に遭遇する。落下する甲冑から蘭が女優を救い、連続殺人犯（スラッシャー）が蘭たちを狙う中、新一は何度も蘭を守る。ベルモット（シャロン・ヴィンヤード）は有希子に「天使が見守っている」と伝える。蘭が階段から落ちそうになった通り魔（ベルモットの変装）を助けようとした際、新一も駆けつけて「人が人を助ける理由に……論理的な思考は存在しねぇだろ？」と言い放った。この場面で、蘭は新一への恋心を自覚する。
- 原作 File 646–651（62巻「殺人犯、工藤新一／新一の正体に蘭の涙」）— 解毒剤試作品を誤飲して新一に戻ったコナンが記憶喪失になり、殺人犯として疑われる。記憶喪失の新一に戻った状態で蘭の手を握り、コナンに戻る直前に「君が言おうとしていることと僕が言おうとしていることは同じだ」と伝える。蘭が新一の手を握ったまま眠り込み、手を握ったまま新一がコナンに縮んだため、コナンはセーターの袖脇を切って着替えることで手をつないだまま服を替え、蘭が目覚めるまで手を離さなかった。
- 原作 File 725–727（69巻「裏切りのホワイトデー」）— ホワイトデー。蘭が「自分だけプレゼントをもらっていない」と落ち込んだ後、郵便で届いたのど飴が新一からだとわかって元気を取り戻す（要確認：のど飴の詳細）。
- 原作 File 743–752（71・72巻「ホームズの黙示録」）— ロンドンで一時的に新一に戻ったコナンは、自分の心ぐらい推理してみろと蘭に詰め寄られ、「オメーは厄介な難事件なんだよ！余計な感情が入りまくってたとえオレがホームズでも解くのは無理だろーぜ！好きな女の心を…正確に読み取るなんて事はな！！」と返して、蘭への想いを告げる（F-REL-002 の経過）。
- 原作 File 921–924（87巻「サクラ組の思い出（蘭GIRL／新一BOY）」）— 4歳の新一が帝丹幼稚園サクラ組で泣いている蘭を発見し、折り紙の折り跡からサクラ形のネームプレートだと推理した（新一の初めての推理）。蘭が「泣いてない！」と言い張り新一が「泣いてた」と言い張る言い争いが二人の出会いの始まり。蘭は最初新一のことが気にいらなかったが、新一はこの瞬間から蘭に夢中になっていたとコナンが独白する。
- 原作 File 1000–1005（94・95巻「紅の修学旅行」）— 清水寺で新一に再会した蘭がキスをして想いを伝える。その後「付き合ってるってことでいいんだよね？」「付き合ってるに決まってんだろ」とメールを交わし、二人の交際が成立する（F-REL-002 回収）。

- 原作 File 879–881（83巻「コナンと平次恋の暗号」）— 麻薬取引の暗号を解いた平次が大阪・戎橋で張り込み中、和葉が容疑者の一人と話しているのを見て動揺し「俺の和葉に何さらしとんじゃ！」と叫んでしまう（その後のいきさつは「かまいたちの宿」の項を参照）。
- 原作 File 909–912（86巻「かまいたちの宿」）— 平次・和葉・コナン・蘭・小五郎が温泉宿を訪れる。宿で「かまいたち」による切りつけ事件が発生し、平次と小五郎も負傷する。コナンは「俺の和葉」発言の音声を聞かせて平次をいじり、少年探偵団全員がその音声のダビングを持っていて、灰原はしばらく着メロにしていたと知った平次は青ざめる。平次はコナンに音声を削除してもらい、和葉に問い詰められると「おのれ！和葉に何さらしとんじゃ！」と言ったのだとはぐらかす。「そないな大事なことをひっかけ橋の上で言うたことにできるか？ボケ」というモノローグから、平次が戎橋（通称ひっかけ橋）ではなく、もっとふさわしい場所で告白しようと決めていることがわかる。

- 原作 File 1067–1069（100巻「不吉な縁結び」）— 平次が縁結びで知られる杯戸神社へこっそり参拝に来ていたことが判明。偶然にも和葉と蘭も同じ神社に来ており、平次は人気アイドルに変装して正体を隠す。最終的に和葉と蘭に変装がばれるが、和葉が「その相手って誰やねん？」と天然を発揮し告白は未成就に終わる。
