# 関係性：恋愛・グループ・友人・ライバル

> **ネタバレあり。** 正体・生死・交際状況など、未読の人には見せないこと。

情報時点は `conventions.md` の「1. 情報時点」に従う。

---

## 目次

| ファイル | 内容 |
|---|---|
| `loves.md` | 恋愛関係（A/B/C/D/E 段階） |
| `groups.md` | グループ・家族・友人・ライバル関係 |

---

## 凡例

### 恋愛関係の段階（loves.md）

| 段階 | 定義 |
|---|---|
| **A** | 交際中・恋人関係が成立 |
| **B** | 相思相愛だが交際は未成立・未確定 |
| **C** | 既婚・夫婦 |
| **D** | 過去の恋人・死別など |
| **E** | 現状片思い（一方のみ恋愛感情あり） |

- 男女の恋愛関係（いわゆるノマカプ）のみを対象とする。
- 原作漫画基準。劇場版・アニオリ等は `[劇場版]` 等のタグを付けて補足。
- 「根拠」欄の File 番号は `conan_db.py` で確認する。確認できなかったものは「要確認」と書く。
- 知識表の記号（◎△✕等）とは **別系統**。

### グループ状態（groups.md）

| 記号 | 意味 |
|---|---|
| `◎` | 活動中 |
| `△` | 一部のみ活動中・休止中 |
| `✕` | 解散・消滅 |
| `?` | 不明・要確認 |

---

## 各エントリの構成

各エントリには `#### 経緯`・`#### 関連伏線`・`#### 考察` の 3 節を置く。

| 節 | 書くこと |
|---|---|
| `#### 経緯` | 関係者の初登場 File・関係が発展した主要エピソード（File 番号・巻・事件名つき） |
| `#### 関連伏線` | 関連する `F-*-*` ID へのリンクと状態 |
| `#### 考察` | **何も書かない（空のままにする）**。考察・推測は `data/foreshadowing/` または `data/open-questions.md` に書く。 |

---

## 更新のしかた

1. File 番号は必ず `python plugins/detective-conan/scripts/conan_db.py` で確認する。
2. 確認できなかった情報は「要確認」と書き、推測で埋めない。
3. 変更後は `python plugins/detective-conan/scripts/lint_data.py` を実行してエラー 0 件にする。
4. 情報時点が変わったら `conventions.md` の更新日も直す。
