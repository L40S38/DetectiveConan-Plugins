[^K1-miyano-shiho]: 灰原は File 179–181（18・19巻）で、縮んだ新一を知っていたことをコナンに明かす。変声機・麻酔銃は日常的に知っている。

[^K1-shonen-tanteidan]: 25 年以上コナンと行動をともにする中で、変声機・麻酔銃が使われる場面を繰り返し目にしているとみられる（個別の確定話数は未特定）。ただし、それがコナンの正体や「眠りの小五郎」の真相と結び付くところまでは理解していない。

[^K1-enomoto-azusa]: File 1126–1128「コナンと梓誘拐したのは誰？」でコナンとともに誘拐・監禁され、その際に麻酔銃の存在を知った。

[^K1-agasa-hiroshi]: File 2（1巻）でコナンの正体を最初に知る。変声機・麻酔銃の開発者。

[^K1-kudo-yusaku]: 工藤夫妻は File 49（5巻）「江戸川コナン誘拐事件」の時点で事情を知っている。

[^K1-hattori-heiji]: 平次が確信した話は要確認（F-KUDO-003）。

[^K1-mori-ran]: 何度もコナン＝新一を疑っているが、そのたびに否定されている（例：File 646–651「殺人犯、工藤新一／新一の正体に蘭の涙」）。疑った場面の一覧は F-REL-001。

[^K1-mori-kogoro]: 自分が眠っている間に事件が解けていることへの違和感の有無は未回収（F-REL-004）。コナンを「賢い」と見る描写は場面による。

[^K1-ooka-momiji]: 「紅の修学旅行」（File 1000–1005）で、一時的に新一に戻ったコナンと京都で対面している。「大岡紅葉の挑戦状」（File 1039–1042）では、紅葉から蘭へのメールで「京都でお会いした工藤新一くんに」と言及があり、面識があることが確定している。

[^K1-iori-muga]: File 1113–1115「執事になった理由」で、平次がコナンと連絡を取って伊織を助ける。伊織がコナンをどう見ているかは要確認。元公安警察官なので表6 にも入れている。

[^K1-akai-shuichi]: 赤井はコナンを「ボウヤ」と呼び、工藤夫妻とも協力している（沖矢昴の件）。コナンが赤井に正体を知られていると把握している根拠の話数は要確認。

[^K1-sera-masumi]: 10 年前に新一と会っている（File 972–974）。コナンを強く疑う言動がある。確信に至った描写とコナン側の認識は要確認。

[^K1-akai-mary]: メアリー自身が縮んでおり、コナンを「同じ境遇」とみている描写がある（要確認：話数）。

[^K1-hondo-eisuke]: Detective Conan World の「コナンの正体を知る人物」一覧に挙がっている（sources.md の C）。原作での該当話とコナン側の認識は要確認。

[^K1-furuya-rei]: コナンの正体に気づいているとみられる言動があるが、コナンの側に確証はない（要確認：代表的な話数）。警察学校時代に幼い新一と会っていた（File 1134–1136「出会っていた５人組」）。K1-6 は「眠りの小五郎」の推理にコナンが関わっているとみている描写による（要確認）。

[^K1-keisatsu-gakko]: 警察学校時代に幼い新一・蘭と会っていた（File 1134–1136「出会っていた５人組」）。コナン登場前に故人となっているため、接近度などは `ー`。

[^K1-kuroba-kaito]: キッドはコナンを「名探偵」と呼び、新一に変装して手助けする場面がある。正体を知っているとする Wiki 記述がある（sources.md の C）。コナン側の認識の話数は要確認（F-KID-006）。

[^K1-rum]: 脇田兼則として毛利探偵事務所の隣にいて、「眠りの小五郎」のファンを名乗る（File 975–977）。コナンをどこまで疑っているかは要確認。

[^K1-vermouth]: File 429–434（42巻「黒の組織と真っ向勝負」）で、コナン（新一）と灰原の正体を知っていることがはっきりする。コナンもそれを知っている。

[^K1-gin]: 新一は死んだと思っている（F-ORG-009）。

[^K1-irish]: [劇場版] 第 13 作『漆黒の追跡者』で、コナンの正体に気づいたが、組織に伝える前に死亡した（要確認：コナン側が把握していたか）。

[^K1-pinga]: [劇場版] 第 26 作『黒鉄の魚影』。コナンの正体に気づいていたとする記述がある（要確認）。

[^K1-wakasa-rumi]: コナンを特別視する言動がある（要確認：話数）。接近度 3 の可能性がある。
