[^K6-furuya-rei]: スコッチ＝諸伏景光は幼なじみで警察学校の同期。潜入中の同僚でもあった。

[^K6-doki]: 警察学校組の 5 人。File 1134–1136（107巻「出会っていた５人組」）で 5 人そろって描かれる。安室透という偽名や、スコッチというコードネームを使い始めた時期と、各人の死亡時期の前後は要確認。

[^K6-halloween]: K6-3（降谷＝公安）と K6-5（景光＝公安）の根拠は [劇場版] 第 25 作『ハロウィンの花嫁』の描写。原作での描写は要確認。萩原研二はこの 2 列の対象外（`?` のまま）。

[^K6-onizuka-hachizo]: 5 人の担当教官（File 1134–1136（107巻「出会っていた５人組」））。

[^K6-kazami-yuya]: File 1113–1115（104・105巻「執事になった理由」）で、伊織を見て「警察学校時代の同期に似ている」と言い、その同期は降谷と同じ「ゼロ」に配属されていたと語る。伊織が元公安（K6-6）であり、自分と同期（K6-7）だったことを認識している。

[^K6-kuroda-hyoe]: 公安とつながり、降谷の上司に当たる立場（要確認：話数）。K6-6：File 1088–1090（102巻「大岡紅葉の甘い罠」）で、伊織を潜入時の偽名「榊原」で呼び、元部下であることを示す。K6-7（伊織と風見の同期関係を知っているか）は明示の描写がなく不明。

[^K6-iori-muga]: 元公安警察官（File 1113–1115（104・105巻「執事になった理由」））。File 1088–1090（102巻「大岡紅葉の甘い罠」）で、喫茶ポアロの回（File 981–983（92・93巻「謎解きは喫茶ポアロで」））に伊織が変装して安室に会いに行っていたことがわかり、安室を公安の人間（降谷）と認識しているとみられる。在職していた時期や、諸伏景光・同期組との接点は要確認。K6-7：File 1113–1115（104・105巻「執事になった理由」）で、風見が伊織を「警察学校時代の同期に似ている」と言い、降谷と同じ「ゼロ」に配属されていたと語る場面がある（風見側からの認識）。伊織の側が風見を同期と認識しているかは、明示の描写がなく要確認（◐）。

[^K6-halloween-keishicho]: K6-3（降谷＝公安）は [劇場版] 第 25 作『ハロウィンの花嫁』の描写による（`†`）。原作での描写は要確認。

[^K6-yosei-no-kuchibiru]: 原作 File 1018–1021（96巻「キッドＶＳ高明狙われた唇」）の「妖精の唇」の回で、「諸伏高明の弟が公安に配属され、任務中に殉職した可能性が高い」ことを知る。スコッチとして組織に潜入していたことまでは知らないので、K6-5 は ◐、K6-4 は ✕。

[^K6-chiba-kazunobu]: K6-1 は [劇場版] 第 25 作『ハロウィンの花嫁』で、警察学校組が同期だったことを認識している描写による（`†`）。原作での描写は要確認。

[^K6-yamamura-misao]: 原作 File 1084「ミッちゃんのお家」（102巻「群馬と長野県境（ボーダー）の遺体」）で、高明から「弟は公安に行ったのだろう」と聞かされる（死は伏せられる）。景光が公安に進んだことは知っているが、殉職したこと、組織に「スコッチ」として潜入していたことは知らない（K6-4 は ✕）。

[^K6-takagi-wataru]: 伊達の後輩。File 1079–1081（101・102巻「高木と伊達と手帳の約束」）で安室と同席するが、安室と伊達の関係には気づいていない（要確認）。

[^K6-sato-miwako]: 松田陣平の同僚だった（File 369–373（36・37巻「揺れる警視庁1200万人の人質」））。萩原研二のことも松田から聞いている（要確認）。警察学校時代の降谷に（大学生として）会ったことがある（[スピンオフ]『警察学校編 Wild Police Story』最終話）。File 1079–1081（101・102巻「高木と伊達と手帳の約束」）で当時のことを思い出し、（安室透として行動中の）降谷に「あなた、前にどこかで会ったことない？」と聞いている。安室透とその時の人物を結び付けているかは要確認（K6-2 は △）。

[^K6-miyamoto-yumi]: 警察学校時代の降谷に会ったことがある（[スピンオフ]『警察学校編 Wild Police Story』最終話）。安室透とその時の人物を結び付けているかは要確認。

[^K6-morofushi-takaaki]: 安室透＝降谷零だと知っている（File 1030「兄さんみたいに」（97巻「36マスの完全犯罪(パーフェクトゲーム)」）— 小五郎から届いた画像の金髪の男が、大学時代に弟から紹介された「降谷零君」だと気づく）。弟・景光が公安に配属され、任務中に殉職した可能性が高いと推理している（File 1021「遺品」（96巻「キッドＶＳ高明狙われた唇」）。File 1084「ミッちゃんのお家」（102巻「群馬と長野県境（ボーダー）の遺体」）でも山村に同じ趣旨を話す）。ただし、**組織内のコードネーム「スコッチ」までは知らないとみられる**（K6-4 は ✕）。降谷が公安であることは、File 1021「遺品」（96巻「キッドＶＳ高明狙われた唇」）・File 1030「兄さんみたいに」（97巻「36マスの完全犯罪(パーフェクトゲーム)」）からの推理でたどり着いているか、あるいは黒田兵衛（降谷の上司格）から直接聞いている可能性が高いが、明言する描写は確認できていない（K6-3 は ◐）。警察学校の同期 5 人については一部を把握している（◐）。

[^K6-hagiwara-chihaya]: 弟・研二と松田陣平の高校時代を知っている（File 1154–1156（108・109巻「指輪の思い出」））。降谷・諸伏景光・伊達を知っているかは要確認。

[^K6-kudo-shinichi]: 幼い頃に 5 人と会っていたことを、蘭の回想で知る（File 1134–1136（107巻「出会っていた５人組」））。スコッチ＝諸伏景光は推理でつかんでいる段階（要確認）。

[^K6-mori-ran]: 幼い頃に 5 人と会っていたことを思い出す（File 1134–1136（107巻「出会っていた５人組」））。彼らが同期の警察官だということまで覚えているかは要確認。

[^K6-akai-shuichi]: スコッチの最期に立ち会った。スコッチが公安の潜入捜査官だと知っていた。

[^K6-gin]: 組織はスコッチが NOC（潜入捜査官）だと突き止めた（F-POL-004）。本名まで知っていたかは要確認。
