[^K5-kudo-shinichi]: 脇田＝ラムは File 1150「混沌の追跡者たち」（108巻「混沌の行先」）で推理によってたどり着き、沖矢昴（赤井）に伝える（決め手は複数：発音・義眼・「時は金なり」のアナグラム・灰原の反応）。キールの CIA は File 605–609（58・59巻「赤と黒のクラッシュ［嫌疑／潔白／決死／殉職］」）。ベルモット＝クリス＝シャロンは、File 242「白の世界」（24巻「黒の組織との再会」）でクリスと判明し、File 433「仮面の下の真実」（42巻「黒の組織と真っ向勝負満月の夜の二元ミステリー」）でクリス＝シャロンと判明する、という 2 段階。

[^K5-miyano-shiho]: File 1144「呼び出された男」（108巻「過去との遭遇」）で脇田に強い恐怖を感じる（組織の気配）が、File 1145「危険な再会」（108巻「過去との遭遇」）時点では体調不良を「殺気を感じただけかも」と自己解釈しており、脇田＝ラムと結び付けて知っている描写はない（現時点では知らない）。バーボンについては、安室を警戒している段階（要確認）。

[^K5-akai-shuichi]: 自分がライ。File 1150「混沌の追跡者たち」（108巻「混沌の行先」）でコナンから脇田＝ラムの推理を聞く（車内で「聞かせてもらおうかボウヤ」と促す）。

[^K5-sera-masumi]: 安室を組織の人間ではないかと疑う描写がある（要確認）。

[^K5-fbi]: FBI は File 605–609（58・59巻「赤と黒のクラッシュ［嫌疑／潔白／決死／殉職］」）でキールが CIA の NOC だと知る。バーボン＝安室は緋色シリーズ（File 891–893（84巻「緋色シリーズ［序章／追求］」）・File 894–898（85巻「緋色シリーズ［交錯／帰還／真相］」））の前後で把握（要確認）。脇田＝ラムは、ジョディはキャメルの報告（File 1150「混沌の追跡者たち」（108巻「混沌の行先」））を受けて調べに向かうため有力。ジェイムズはFile 1150「混沌の追跡者たち」（108巻「混沌の行先」）に登場するが、どこまで知っているかは明示されない（不明）。

[^K5-andre-camel]: File 1144–1146（108巻「過去との遭遇」）で脇田と顔を合わせ、2 年前に会ったことを思い出す。File 1147「混沌の正念場」（108巻「混沌の行先」）で「ラムの片目は義眼と聞いていたが…もしかしてこの男の事か!?」と疑い、File 1150「混沌の追跡者たち」（108巻「混沌の行先」）でジョディに報告する。

[^K5-hondo-hidemi]: 自分がキール。組織の中でバーボン・ベルモットと接している。

[^K5-hondo-eisuke]: 姉が CIA の諜報員であることを File 585–586（56巻「赤と黒のクラッシュ［発端／血縁］」）〜File 605–609（58・59巻「赤と黒のクラッシュ［嫌疑／潔白／決死／殉職］」）で知る。

[^K5-furuya-rei]: 自分がバーボン。キールが組織への裏切り者・協力者（赤井の死の偽装に加わった）だと File 895「緋色の尋問」（85巻「緋色シリーズ［交錯／帰還／真相］」）で推理しているが、その所属が CIA だと知っている描写は確認できていない（不明）。ラムの正体を知っているかは要確認。

[^K5-kuroda-hyoe]: 降谷がバーボンとして潜入していることを知っている立場（要確認）。脇田＝ラムは知らない（要確認）。

[^K5-org]: 組織の構成員はライ（赤井）の正体を知っている。キールの CIA は知らない。ラムの正体（脇田兼則）を知っているのはジンだけ（File 1065–1066（100巻「黒ずくめの謀略［狩り／上陸／正体］」）でウォッカ・キャンティの会話により確定）。ウォッカ・キャンティ・コルンは「顔と偽名」までしか知らない。シャロン＝クリスを知っているかは要確認。

[^K5-wakasa-rumi]: File 1148–1149（108巻「混沌の行先」）で、脇田の声に「聞いた事があるような…お寿司屋さん？」と気づき、左目の眼帯を見たがって肩をつかむ（確定）。File 1144–1146（108巻「過去との遭遇」）・File 1147–1150（108巻「混沌の行先」）では、コナン・赤井・キャメル・若狭が相次いで脇田＝ラムに気づく。上記の K5-6 のセルはこの一連の描写に基づく。

[^K5-kuroba-toichi]: ベルモット（シャロン）に変装を教えた師（F-KID-002）。どこまで知っているかは要確認。
