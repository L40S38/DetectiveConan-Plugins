[^K3-akai-shuichi]: [劇場版] 第24作『緋色の弾丸』のラストで、変装した沖矢を「小僧」と呼んだメアリーに対し、沖矢（秀一）が微笑む場面が「気づいている」根拠としてファンの間で広く語られているが、セリフでの明言はなく解釈の域（映画自体が意図的に曖昧にしている）。原作に該当描写はない。母とエレーナが姉妹だと知っているかは要確認。

[^K3-haneda-shukichi]: 兄の生存を知る協力者。File 1016「駐禁の標識」（96巻「標的（ターゲット）は警視庁交通部」）で兄に「由美たんを守って」とメールし、沖矢の姿の赤井が由美を守る。File 1046「名人の奥の手」（98巻「太閤名人の将棋盤［初手編／妙手編／王手編］」）では赤井が素顔で秀吉を救出し、秀吉が「母さんにはまだ兄さんが生きていると伝えていない」と話す（伝えていない理由が意図的な隠匿か、連絡が取れないためかは原文未確認）。沖矢＝赤井の変装まで知っているかは不明。

[^K3-sera-masumi]: 母と一緒に行動しており、母が縮んでいることを知っている。兄・秀一の生存は疑っている段階：File 801「全然笑わない人」（76巻「１ミリも許さない」）でスカー赤井（安室の変装）を見て「まさか」と思う→File 821「ミステリートレイン［交差］」（78巻「漆黒の特急［ミステリートレイン］［発車／隧道／交差／終点］」）でベルモット変装の赤井に「死んだと聞いた」と驚く→File 859「截拳道vs.空手」（81巻「容疑者か京極真」）で「兄は死んだと聞いた」と話す→File 1038「隠すより現る」（98巻「骨董盆は隠せない」）で、父・務武の口癖「50:50」が兄にも伝わっていたとメアリーから聞き、沖矢も同じ口癖を使うことに気づいて「まさかね？」と疑うが、死んだはずだと否定しようとする。

[^K3-akai-mary]: 自分が宮野エレーナの姉。息子・秀一の生存については、[劇場版] 第24作『緋色の弾丸』の格闘シーン・ラストで、沖矢の戦い方や言動から察している、と読むファン考察が多いが、本人が明言する場面はなく解釈の域（映画自体が意図的に曖昧にしている）。原作に該当描写はない。

[^K3-kudo-shinichi]: 赤井の死の偽装に関わっており、沖矢昴の正体を知っている（File 894–898（85巻「緋色シリーズ［交錯／帰還／真相］」））。10 年前に赤井家と会っている（File 972–974（92巻「さざ波の魔法使い」））。領域外の妹が縮んでいることにも気づいている（要確認：話数）。

[^K3-miyano-shiho]: 赤井は死んだと思っている。沖矢昴には当初「組織のにおい」を感じて警戒するが、File 800「立体交差の思惑」（76巻「探偵たちの夜想曲［ノクターン］［事件／誘拐／推理／バーボン］」）で「そんな顔をするな…」と言われ、File 802「そんな顔をするな…」（76巻「１ミリも許さない」）で姉の恋人・諸星大の同じ言葉を思い出して沖矢と結び付けて疑うようになる（以後「昴さん」と呼び警戒を解く）。沖矢＝赤井（＝諸星大）だと確信している描写はない。自分と赤井家の血縁は知らない（要確認）。

[^K3-kudo-yusaku]: 沖矢昴への変装と、赤井の死の偽装に協力している（File 894–898（85巻「緋色シリーズ［交錯／帰還／真相］」））。

[^K3-fbi]: File 894–898（85巻「緋色シリーズ［交錯／帰還／真相］」）の後、赤井の生存と沖矢昴の件を知っている（要確認：明示された話数）。

[^K3-hondo-hidemi]: 来葉峠で赤井を撃つ役を演じ、死の偽装に加わっていた（File 894–898（85巻「緋色シリーズ［交錯／帰還／真相］」）で明かされる）。

[^K3-furuya-rei]: File 894–898（85巻「緋色シリーズ［交錯／帰還／真相］」）で赤井の生存を確信する。沖矢昴＝赤井については、File 896–897（85巻「緋色シリーズ［交錯／帰還／真相］」）で工藤邸に忍び込み沖矢の襟元を確かめるが変装した優作で失敗、File 957「裏切りの真相」（90巻「裏切りのステージ」）で沖矢が左利きだと気づき疑いが再燃、File 1012「ぬかったな」（95巻「迷宮カクテル」）で素顔の赤井と銃を向け合い「ぬかったな、赤井秀一」と告げる（事実上知っている扱い。「沖矢＝赤井」と言葉で明言する場面は確認できていない）。

[^K3-miyamoto-yumi]: 秀吉の恋人。File 1043–1046（98巻「太閤名人の将棋盤［初手編／妙手編／王手編］」）冒頭で秀吉を尾行する場面で、コナンに「秀吉は亡くなった羽田浩司の後を継ぐ形で羽田家の養子になった」「兄と妹がいる。会ったことはないが、秀吉と似たような性格だろうと想像する」と話す。会ったことはなく、想像の域を出ない（K3-4 は 〇）。秀吉が名人であることは知っている。

[^K3-gin]: 赤井は来葉峠で死んだと思っている（要確認：現在も疑っていないか）。
