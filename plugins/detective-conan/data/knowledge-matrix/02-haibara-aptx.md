[^K2-kudo-shinichi]: File 179–181（18・19巻「黒の組織から来た女大学教授殺人事件［2］」）で灰原が自分の素性を明かす。両親については、灰原から聞いた範囲で知っている（要確認：どこまでか）。

[^K2-kudo-yusaku]: 工藤夫妻が灰原の素性を知っていることを示す話数は要確認。

[^K2-hattori-heiji]: 平次が灰原も縮んだ人物だと知っている描写の話数は要確認。

[^K2-mori-ran]: File 13–16（2巻「奇妙な人捜し殺人事件」）で、広田雅美（宮野明美）に会っている。明美の妹が灰原だとは知らない。

[^K2-akai-shuichi]: 宮野明美の元恋人（File 599–604（58巻「赤と黒のクラッシュ［覚醒／攪乱／偽装／遺言／嫌疑］」））。灰原を守るために沖矢昴として工藤邸に住む。宮野夫妻をどこまで知っているかは要確認。

[^K2-akai-mary]: 宮野エレーナの姉なので、エレーナとその娘たちを知っている（要確認：志保の現在の姿を知っているか）。

[^K2-jodie-starling]: FBI として組織のシェリーの情報を持つ（要確認）。宮野明美は赤井の元恋人として知っている。

[^K2-furuya-rei]: 子どもの頃、黒ウサギ亭の一件で宮野エレーナ・厚司・明美（志保の両親と姉）に会っている（File 1009–1012（95巻「迷宮カクテル」））。バーボンとしてミステリートレインでシェリーを追った（File 818–824（78巻「漆黒の特急［ミステリートレイン］［発車／隧道／交差／終点］」））。灰原＝シェリーだと知っているか（K2-1）は要確認。

[^K2-rum]: 組織の No.2 として、シェリーと APTX4869、宮野夫妻の研究を知っている立場（要確認：どこまでかの描写）。

[^K2-vermouth]: File 429–434（42巻「黒の組織と真っ向勝負満月の夜の二元ミステリー」）で灰原（シェリー）を狙う。灰原が縮んだことを知っている。

[^K2-gin]: シェリーは組織から逃げたと知っているが、灰原とは結び付けていない。[劇場版] 第 26 作『黒鉄の魚影』では一時的に灰原の拉致を命じたが、最終的に疑いは消えた（F-APTX-011）。

[^K2-org-deceased]: ピスコは File 238–242（24巻「黒の組織との再会」）で、縮んだ灰原の姿を見た。直後にジンに射殺され、組織には伝わらなかった。

[^K2-pinga]: [劇場版] 第 26 作『黒鉄の魚影』で灰原＝シェリーに気づいたが、死亡した。

[^K2-wakasa-rumi]: File 1163「先生の贈り物」〜File 1166「先生のお返し」（単行本未収録／サンデー 2026 年 30〜33 号）で灰原との関わりが描かれた（D 速報系による）。

[^K2-naomi-argento]: [劇場版] 第 26 作『黒鉄の魚影』。小学生の頃に宮野志保と知り合っており、老若認証で灰原＝志保にたどり着いた。
