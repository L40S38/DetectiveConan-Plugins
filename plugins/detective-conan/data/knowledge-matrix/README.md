## 凡例

### 二値の列

| 記号 | 意味 |
|---|---|
| `●` | 確定で知っている |
| `◐` | 推理でたどり着いているが確証の描写がない、または一部だけ知っている |
| `△` | 疑っている・違和感を持っている |
| `✕` | 知らない |
| `ー` | 本人である・該当しない（故人で時期が合わないなど） |
| `?` | 描写がなく不明。**ベースライン（2026-09-29）では、確かめきれていないセルも `?` にしている** |

- 根拠が正史外（劇場版・アニオリ・スピンオフ）の描写だけのときは `†` を付ける（例：`●†`）。
- 自明でないセルには脚注を付ける。脚注は 1 人につき 1 つで、列ごとの根拠をまとめて書く。

## 行の選び方

すべての表で共通のルールにする（統一感と保守性のため）。

- グループ分けは `characters.md` の「(b) 人物カード」の分類（コナン陣営／毛利家・友人・帝丹小／大岡家（京都）／FBI・CIA・赤井家／警察・公安／キッド陣営／黒ずくめの組織／宮野家／羽田浩司事件の関係者／劇場版オリジナル（組織以外）／その他）をそのまま使う。表ごとに違うグループ分けをしない。
- **1 つでも列が `✕`（二値の列）／`1`（接近度の列）以外なら、個別の行にする。** `?`（未確認）も「✕ ではない」ので個別行にする。同じ記号の組み合わせに見えても、人物によって根拠が違うことがあるので、まとめない。
- 各グループの中で、個別の行にしなかった残り全員（そのテーマについて描写が一切ない、または全列が `✕`／`1` の人物）は、グループごとに 1 行へまとめる。
  - 書式：`| ほかの「<グループ名>」（全員 ✕。characters.md 参照） | ✕ | ✕ | … | |`（接近度の列があれば `1` にする）
  - この行は特定の人物 ID を持たない。`characters.md` にそのグループの人物が増えても、個別の行を作らない限り自動的にこの行でカバーされる（保守性のため。同期を取る必要がない）。
  - グループの全員が個別の行になった場合は、まとめ行は作らない。
- 人物名の後ろに `characters.md` の人物 ID を書く（まとめ行を除く）。
