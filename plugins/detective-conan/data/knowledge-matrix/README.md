## 凡例

### 記号

どの列も、次の記号のどれかで書く。

| 記号 | 意味 |
|---|---|
| `◎` | 確定で知っている |
| `〇` | 推理でたどり着いているが確証の描写がない、または一部だけ知っている |
| `△` | 疑っている・違和感を持っている（一度でも疑ったこと・違和感を持ったことがあれば、あとで打ち消していても `△`）。または、その情報が口に出された・示された場面にいたが、聞いた・見たかがわからない（その回に出ているだけで、その場面にいたかを確かめていないときは `?`） |
| `✕` | 知らない。知らないと言い切れる根拠（その情報に触れる機会がない、知らないとわかる描写がある）があるときだけ使う |
| `ー` | 本人である・該当しない（故人で時期が合わないなど） |
| `?` | 知っているかがわからない。おもに、その場面にはいなかったが、これまでの物語の流れから、あとで伝え聞いていてもおかしくない（ほかの人物から伝わる経路がある、有名人に関わる事実など）とき。ほかに、関わる場面はあるがその情報は口に出されていない・示されていないときと、確かめきれていないとき（要確認）も `?` にする。**ベースライン（2026-09-29）では、確かめきれていないセルも `?` にしている** |

- 根拠が正史外（劇場版・アニオリ・スピンオフなど、原作には描かれていないが青山先生が監修している作品）の描写だけのときは `†` を付ける（例：`◎†`）。
- 自明でないセルには脚注を付ける。脚注は 1 人につき 1 つで、列ごとの根拠をまとめて書く。
- 故人で、その情報が生まれる前（その出来事より前）に死んでいる列は `ー` にする。時期の前後がわからないときは `?` にする（前後にかかわらず触れる機会がなければ `✕`）。`ー` の列がある人物は、まとめ行に入れず個別の行にする。
- 世間に知られた事実（新一の評判、秀吉の名人位、羽田浩司の死など）は、その人物・事件と関わりがある人物（身近な人から聞ける、同じ場面に居合わせたなど）だけ、描写がなくても `?` にする。報道で見聞きするほかに触れる機会がない人物は、`✕` にする。どの列がこれに当たるかは、各表の列の説明に書く。
- ほかの人物から伝わる経路は、下の「伝わる経路」にまとめる。

### 伝わる経路

ある人物が知っていることが、ほかの人物に伝わっていてもおかしくない関係（伝わる経路）を、下の「経路の一覧」にまとめる。`?` と `✕` を分けるときに使う。

- 受け取る人の列は、伝える人がその列を `◎`・`〇`・`ー`（本人）にしていて、受け取る人が知っている・知らないとわかる描写がなければ `?` にする。伝える人の値が正史外の描写だけによるとき（`◎†` など）は `?†` にする。脚注には「経路「<経路の名前>」」と書く。
- 経路の中にいても、伝わっていないことがはっきりしている場合（例：お茶会で話された内容を、コナンは知らされていない）と、伝える人がその受け取る人に隠しているとみる情報は、`✕` にする。そのセルは「経路の例外」に書き、脚注にも理由を書く。
- 伝える人の列が `△`・`?` のときは、経路では伝わらないものとする（経路をたどって `?` を広げない）。
- 物語が進んで経路が変わったら（人が増える・減る、隠していたことを話すなど）、この 2 つの表を直し、脚注を経路の名前で検索して見直す。`lint_data.py` は、伝える人が `◎`・`〇`・`ー` で受け取る人が `✕` のセルのうち、「経路の例外」に書いていないものを警告する。

### コナンの把握（各表の右端の列）

各表のいちばん右（根拠の左）に「コナンの把握」の列を置く（表1 なら K1-7）。その人物がこの表の情報を知っていることを、コナンが把握しているかを、上の記号で書く。

- 工藤新一本人の行と、この表の情報を何も知らない行（ほかの列がすべて `✕`（`✕†` を含む）・`ー` の行、まとめ行）は `ー` にする。
- 判断に入れるのは、その行の `◎`・`〇` の列（`◎†`・`〇†` を含む）だけにする。`△`・`?`・`✕`・`ー` の列は入れない。
- 判断に入れる列ごとに、コナンがそれをどこまで把握しているかを、次の段階に分ける。
  - A 気づいている：コナンのモノローグ・発言などから、その人物がそれを知っていることにコナンが気づいているとはっきりわかる。コナンが情報源のとき（コナンが伝えた・見せた）、本人がコナンに直接話した・頼んだ・コナンと一緒に推理したとき、コナンが本人の前で推理を話したときも、ここに入る。
  - B 材料がある：コナンがその場面を見た・聞いた（盗聴を含む。相手はコナンに向けて言っていない）、第三者から伝わった、ほかの描写から推せる、など、気づくための材料をコナンが持っている。ただし、気づいたとわかるモノローグ・発言はない。
  - C そぶりだけ：コナンが気づいていそうなそぶりを見せるが、気づいているかはわからない。
  - D 材料がない：コナンはその場面を見ておらず、伝わる描写もない。その人物の心の中だけのことや、こっそり見ていたことも、ここに入る。コナン自身がその情報を知らない（工藤新一の行のその列が `✕`・`△`）ときも、ここに入る。
  - 未確認：コナンがその場にいたか、あとで伝わったかを、まだ確かめていない。
- 記号は次のとおりにする。
  - `◎`：どの列も A
  - `〇`：A か B の列があり、全部が A ではない
  - `△`：A・B の列がなく、C の列がある
  - `✕`：どの列も D
  - `?`：A・B・C の列がなく、未確認の列がある
- `◎`・`〇` の列がひとつもなく、`△` か `?` の列がある行（何を知っているかがまだわかっていない行）は `?` にする。
- `†` は、段階の判断とは別に、根拠にした描写がどこのものかで付けるかどうかを決める（ほかの列と同じ）。「コナンの把握」の判断の根拠が、どれも正史外の描写のときに付ける。原作の描写がひとつでも根拠に入っていれば付けない。
- 脚注には、列ごとに A〜D・未確認のどれに当たるかと、その根拠を書く。未確認の列には「要確認」と付ける。

## 行の選び方

すべての表で共通のルールにする（統一感と保守性のため）。

- グループ分けは `characters.md` の「(b) 人物カード」のグループ（`###` の見出し）をそのまま使い、同じ順に並べる。表ごとに違うグループ分けをしない。各グループの先頭には見出し行（`| **<グループ名>** |  |  | … |`）を置く。
- **「コナンの把握」以外の列が 1 つでも `✕` 以外なら、個別の行にする。** `?`（未確認）も `✕†`（正史外の描写だけで「知らない」とわかる）も「`✕` ではない」ので個別行にする。同じ記号の組み合わせに見えても、人物によって根拠が違うことがあるので、まとめない。
- 個別の行は、グループの中で `characters.md` の順に並べる。
- 各グループの中で、個別の行にしなかった残り全員（全列が `✕` の人物）は、グループごとに 1 行へまとめ、グループの最後の行に置く。
  - 書式：`` | ほかの「<グループ名>」：<名前> `<人物 ID>`、<名前> `<人物 ID>`、… | ✕ | ✕ | … | ー | | ``（名前と ID は `characters.md` の順に、残り全員を書く）
  - グループの全員が個別の行になった場合は、まとめ行は作らない（あれば消す）。まとめ行の無いグループで、まとめ行に入る人物が出たら、グループの最後の行として作る。
- 人物名の後ろに `characters.md` の人物 ID を書く。
- `characters.md` に人物を足したら、どの表でも、個別の行かまとめ行のどちらかに入れる。
  - その表の情報に触れる機会が無い（関わる場面も、ほかの人物から伝わる経路も無い）人物は、どの列も `✕` にしてまとめ行に入れる。調べていないというだけで `?` の行は作らない（伝わる経路があるかまで調べて決める）。
  - 関わる場面はあるが知っているかがはっきりしない列と、関わる場面は見つからないが知っていてもおかしくない列は、記号の `△`・`?` の意味に従って書いて個別の行を作り、脚注に理由と「要確認」を書く（場面があれば話数も書く）。
- 正体のわからない老人（ベーダーさん `C-beda-san`・鷹ジジイ `C-taka-jiji`）の正体の候補（大岡家のご隠居・羽田康晴・羽田市代・赤井務武・烏丸蓮耶）は、どの表でも、老人のどちらかが `✕` 以外の列を `?` にした個別の行にする（表1 では、老人本人の行も候補の行にそろえている）。候補の説と老人たちの場面は `characters.md` のカードに書き、脚注にはその表の値の根拠だけを書いて、カードを参照する。
- `characters.md` にグループが増えたら、どの表にも、`characters.md` と同じ位置に見出し行を足す。
- 漏れ・重複・並び順・グループの食い違いは `lint_data.py` が見つける。
