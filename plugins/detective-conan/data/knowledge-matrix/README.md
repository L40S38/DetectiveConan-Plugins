## 凡例

### 二値の列

| 記号 | 意味 |
|---|---|
| `●` | 確定で知っている |
| `◐` | 推理でたどり着いているが確証の描写がない、または一部だけ知っている |
| `△` | 疑っている・違和感を持っている |
| `✕` | 知らない |
| `ー` | 本人である・該当しない（故人で時期が合わないなど） |
| `?` | 描写がなく不明。**ベースライン（2026-09-29）では、確かめきれていないセルも `?` にしている** |

- 根拠が正史外（劇場版・アニオリ・スピンオフ）の描写だけのときは `†` を付ける（例：`●†`）。
- 自明でないセルには脚注を付ける。脚注は 1 人につき 1 つで、列ごとの根拠をまとめて書く。

### 接近度（段階値の列）

**表1 K1-1：コナン＝工藤新一への接近度**

| 値 | 意味 |
|---|---|
| `4` | 同一人物だと知っている（コナンも、相手が知っていると分かっている） |
| `3` | 推理でたどり着いているが、コナンの側はそこまで見抜かれているという確証を持っていない |
| `2` | 新一ではないかと疑ったことがある（否定されて保留にしている場合を含む） |
| `1` | コナンと新一を結び付けていない |
| `ー` | 本人、または該当しない |
| `?` | 不明 |

**表2 K2-1：灰原哀＝宮野志保（シェリー）への接近度**

| 値 | 意味 |
|---|---|
| `4` | 灰原＝宮野志保＝シェリーだと知っている |
| `3` | 推理でたどり着いているが確証はない |
| `2` | 同一人物だとは知らないが、組織に関係していそうだと気づいている |
| `1` | 普通の子供だと思っている |
| `ー` | 本人、または該当しない |
| `?` | 不明 |

**表3 K3-1：領域外の妹（メアリー）が縮んでいることへの接近度**

| 値 | 意味 |
|---|---|

| `1` | 気づいていない |
| `ー` | 本人、または該当しない |
| `?` | 不明 |

## 行の選び方

- 表ごとに、そのテーマに関わる人物だけを並べる。
- 警察関係者は全員、表1と表6に入れる。今はほとんど `✕` でも、どこで変わったかを追えるようにするため。小林澄子のように、今は本筋にほとんど関わっていない人物も同じ扱いにする。
- キッド陣営は表1と表7に入れる。ベルモットとつながりのある黒羽盗一は表5にも入れる。
- 人物名の後ろに `characters.md` の人物 ID を書く。
