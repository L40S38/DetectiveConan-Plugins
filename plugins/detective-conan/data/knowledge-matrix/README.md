## 凡例

### 記号

どの列も、次の記号のどれかで書く。

| 記号 | 意味 |
|---|---|
| `◎` | 確定で知っている |
| `〇` | 推理でたどり着いているが確証の描写がない、または一部だけ知っている |
| `△` | 疑っている・違和感を持っている |
| `✕` | 知らない |
| `ー` | 本人である・該当しない（故人で時期が合わないなど） |
| `?` | 描写がなく不明。**ベースライン（2026-09-29）では、確かめきれていないセルも `?` にしている** |

- 根拠が正史外（劇場版・アニオリ・スピンオフ）の描写だけのときは `†` を付ける（例：`◎†`）。
- 自明でないセルには脚注を付ける。脚注は 1 人につき 1 つで、列ごとの根拠をまとめて書く。

### コナンの把握（各表の右端の列）

各表のいちばん右（根拠の左）に「コナンの把握」の列を置く（表1 なら K1-7）。その人物がこの表の情報を知っていることを、コナンが把握しているかを、上の記号で書く。

- 工藤新一本人の行と、この表の情報を何も知らない行（ほかの列がすべて `✕`・`ー` の行、まとめ行）は `ー` にする。
- 一部の情報だけを知っている、知っていることを知られている、などの細部を示す必要があるときは、根拠（脚注）にまとめて書く。

## 行の選び方

すべての表で共通のルールにする（統一感と保守性のため）。

- グループ分けは `characters.md` の「(b) 人物カード」の分類（コナン陣営／毛利家・友人・帝丹小／大岡家（京都）／FBI・CIA・赤井家／警察・公安／キッド陣営／黒ずくめの組織／宮野家／羽田浩司事件の関係者／劇場版オリジナル（組織以外）／その他）をそのまま使う。表ごとに違うグループ分けをしない。
- **「コナンの把握」以外の列が 1 つでも `✕` 以外なら、個別の行にする。** `?`（未確認）も「✕ ではない」ので個別行にする。同じ記号の組み合わせに見えても、人物によって根拠が違うことがあるので、まとめない。
- 各グループの中で、個別の行にしなかった残り全員（そのテーマについて描写が一切ない、または全列が `✕` の人物）は、グループごとに 1 行へまとめる。
  - 書式：`` | ほかの「<グループ名>」：<名前> `<人物 ID>`、<名前> `<人物 ID>`、… | ✕ | ✕ | … | ー | | ``（名前と ID は `characters.md` の順に、残り全員を書く）
  - `characters.md` に人物を足したら、どの表でも、個別の行かまとめ行のどちらかに入れる。漏れと重複は `lint_data.py` が見つける。
  - グループの全員が個別の行になった場合は、まとめ行は作らない。
- 人物名の後ろに `characters.md` の人物 ID を書く。
