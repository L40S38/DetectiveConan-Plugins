# 参考サイト

research スキルが Web で調べるときは、このファイルの信頼度の順に当たる。
URL はすべて 2026-09-29 に開けることを確認した。開けなかったもの・運営元を確かめられなかったものは載せていない。

## (a) 信頼度の定義

| 信頼度 | 定義 | 扱い |
|---|---|---|
| **A 公式** | 小学館・読売テレビ・TMS・劇場版製作委員会などが運営 | そのまま事実として使える |
| **B 準公式** | 作者インタビュー・公式ガイドブックが載っている媒体、その書誌情報 | `[公式発言]` タグを付けて使う |
| **C ファン Wiki** | 出典付きで編集されている事典系サイト | 話数を A または database で確かめてから使う |
| **D 考察・速報** | 個人ブログ、まとめ、ネタバレ速報 | 最新話の把握と説の収集に使う。事実は A/C で裏を取る。説は `[ファン説]` |

### B 準公式

作者インタビューや公式ガイドはネットで全文を読めないことが多い。「どこに何が載っているか」の索引として使う。

| 名称 | 何が載っているか | 使い方 |
|---|---|---|
| 週刊少年サンデー誌面・巻末コメント | 作者コメント、連載告知 | 掲載号を出典に書く |
| サンデーうぇぶり配信の作者コメント | 例：2017-12-13 配信の作者コメントでボスの正体に言及（`F-ORG-002` の回収欄を参照） | 配信日を出典に書く |
| 劇場版パンフレット・公開時のインタビュー記事 | 劇場版の設定、作者の監修コメント | 媒体名と日付を書く |
| 公式ガイドブック（「名探偵コナン 公式ガイド」系・特別編集本） | 人物設定、年表 | 書名と版を書く。中身を確かめられないときは「要確認」 |

## (c) 用途別の逆引き

| 調べたいこと | 見る順番 |
|---|---|
| File ↔ 巻・事件名・話タイトル | database の CSV → 名探偵コナン編纂室 → DCW：漫画の話数一覧 |
| 人物がどの事件に出たか | database の `Title-MainCharacter.csv` / `Title-GuestCharacter.csv` → 編纂室 |
| アニメ話数 ↔ 原作 | 読売テレビ公式 → Wikipedia アニメエピソード一覧 → DCW：アニメの話数一覧 |
| 最新話の内容 | WEBサンデー・うぇぶり（掲載の有無） → D の速報系（内容）。事実は 2 サイト以上で一致したものだけ使う |
| 作者の発言 | B の媒体 → それを引用している C/D（孫引きのときは「要確認」） |
| 正体を知っている人 | `knowledge-matrix/` → DCW：コナンの正体を知る人物 |
| 劇場版の設定 | 劇場版公式 → Wikipedia の作品記事 |
| 組織メンバーの本名・コードネーム | `characters.md` → Wikipedia「黒ずくめの組織」 |

## (d) 検索のコツ

- 話数で探す：`名探偵コナン "File 1150"`、`コナン 1150話 ネタバレ`
- 編纂室の中を探す：`site:websunday.net/conandb 赤井`
- 英語 Wiki 向けには英語名で探す：Rum、Bourbon、Kir、Hyoue Kuroda、Rumi Wakasa、Tsutomu Akai、Mary Sera
- 最新話は「話数＋ネタバレ」「話数＋サンデー＋号数」で探し、2 サイト以上で内容を突き合わせる
- 要約ツール（WebFetch など）の出力は細部を取り違えることがある。話数・人物名は必ず原文か database で確かめる
